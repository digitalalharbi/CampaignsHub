# خطة العمل المعتمدة من المالك — 2026-11-16

مرجع لأي جلسة أو مطوّر يكمل العمل. التنفيذ على دفعات صغيرة، كل دفعة بطلب دمج مستقل واختبار على الموقع الحي.

## لهجة النظام (ملزمة)
العربية السعودية البيضاء، مهنية بسيطة وواضحة. التنبيه = المشكلة بالرقم ثم الإجراء.
مثال: «وصل الإنفاق إلى 90% من الميزانية، والمتبقي 1,500 ر.س. يُنصح بمراجعة التجديد.»
لا مسميات جديدة للأقسام: «العمليات» يبقى «العمليات».

## الترتيب التالي
1. **مفتاح المنصة وحدود الاستخدام** — مفتاح AI واحد في لوحة الأدمن (مشفّر، يظهر آخر 4 أحرف فقط)؛ `ModelClientFactory` يرجع إليه حين لا يوجد مفتاح للمساحة؛ حد شهري لكل مستخدم حسب الباقة، عدّاد ظاهر، وعند الوصول للحد رسالة «وصلت حدك الشهري» وزر «ارفع الحد». مفتاح العميل الخاص اختياري ولا يُحسب عليه الحد.
2. **المساعد الذكي العائم** — زر في كل الصفحات، لوحة جانبية، أسئلة جاهزة، أي إجراء يظهر كبطاقة اعتماد/رفض (يستخدم `AgentToolbox` الحالي).
3. **إعادة بناء «العمليات»** — التبويبات: «التنبيهات» (تضم التوصيات والموافقات) · «المهام» · «الأتمتة». كل بطاقة: ماذا حدث بالرقم، رسم صغير يوضح السبب، متى ينتهي أو يتفاقم، الإجراء، المصدر وآخر تحديث. دمج المكرر، وإخفاء أي تنبيه بلا رقم أو مصدر.
4. **خادم MCP** — المرحلة 1: `/mcp` (JSON-RPC عبر HTTP) برمز وصول شخصي، نفس أدوات الوكلاء ونفس الصلاحيات والعزل؛ يعمل مع Claude Desktop/Code وGemini CLI ومنصة OpenAI للمطورين. المرحلة 2: OAuth ليُضاف كموصل داخل claude.ai وChatGPT.
