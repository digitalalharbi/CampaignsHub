# Campaign-Management Audit — CampaignsHub (honest, code-level)

> Method: inspected code + running app, NOT prior reports. Demo/seeded data or a rendered page is NOT counted as real-data completeness. Labels: Implemented · Partially Implemented · UI Only · Demo Only · Backend Ready · Real Data Ready · Missing · Blocked by Credentials.

## Verdict
**Partly.** CampaignsHub has a genuinely strong *foundation* for a unified campaign command center — a real normalized-metrics layer (`app/Domains/Metrics`: `NormalizedMetric` DTO with provider mapping, currency/timezone conversion, attribution window, data-freshness, `is_demo`, `sync_run_id`; `DailyMetric`; `MetricsAggregator`), a taxonomy engine driving classifications, and honest awaiting-credentials connectors for the 6 ad platforms. But it is **not yet** a full command center in UX terms: the dashboard and campaigns pages are project+range-scoped views over **demo data**, there is **no live provider→metrics sync pipeline** (no queued sync jobs), campaign classification/comparison/needs-attention UX is thin, and the marketing preview is a bespoke component that does **not** reuse the real dashboard (parity risk the user flagged). Much of the "live" gap is legitimately **Blocked by Credentials**; a large amount of value is **buildable now without credentials** (unified filters, objective KPIs, comparison, details, demo-data quality, alignment).

## Marketing-preview ↔ real-Dashboard parity (key risk)
The homepage v5 dark preview is hand-built for marketing; the authenticated dashboard is a separate component. They must converge on ONE shared overview component so "what you see before login = an honest, labeled demo of what you get after login." This is **buildable now** (item 2 in the plan) and should precede further homepage polish.

## Buildable NOW (no credentials) vs Blocked by Credentials
- **Buildable now:** shared CampaignOverview component; dashboard unified filters + objective KPIs + saved views/compare; campaign classification/view-modes/comparison; campaign details depth; metric-normalization surfacing + canonical-metric doc; **Sandbox-driven sync pipeline** (SyncRun + jobs against `SandboxAdvertisingConnector`) so the whole data flow works end-to-end on demo data; demo-data math consistency; analytics/reports/alerts alignment to the unified source; integrations UI (compact grid + drawer with honest states).
- **Blocked by Credentials (keep honest states):** real OAuth + live token refresh + live metric pulls for Meta/Google/TikTok/Snapchat/X/LinkedIn/GA4/Drive/Stores/CRM/Email/SMS/WhatsApp/Payment. Never show Connected/Synced/Paid/Sent/Live unless a real op occurred.
